# TechTrends — Galerie des tendances

Projet React et TypeScript réalisé avec Vite pour le TP « React, premier contact ».

La galerie affiche les technologies fournies dans le TP.
Les articles viennent de DEV Community et les tâches des issues publiques du projet React sur GitHub. La liste des produits
utilise l'API du TP3 sur `http://localhost:3000/api/produits` si elle est lancée.

```bash
npm install
npm run dev
```

Pour préparer et vérifier le build :

```bash
npm run build
npm run preview
```
